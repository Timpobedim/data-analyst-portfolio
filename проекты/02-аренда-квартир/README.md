# От чего зависит цена аренды квартиры

**Вопрос:** что сильнее влияет на цену аренды — площадь, район или этаж?

**Данные:** 8 000 объявлений: район, площадь, комнаты, этаж, расстояние до центра, цена и срок публикации. Набор воспроизводим по зерну и лежит рядом в `данные.csv`.

**Метод:** границы выбросов по межквартильному размаху, медианы вместо средних, корреляция Спирмена и критерий Манна–Уитни для сравнения этажей.

## Главное

- Площадь объясняет цену лучше всего: связь по Спирмену **0,86**.
- Район добавляет к цене квадратного метра до **81%**: между самым дорогим и самым дешёвым районом разница почти вдвое.
- Первый и последний этажи дешевле, и различие значимо, но размер эффекта пренебрежимо мал (−0,15): на цену это влияет меньше, чем кажется.
- Половина объявлений уходит быстрее 37 дней.

## Что здесь показано отдельно

Одно объявление с опечаткой в нулях сдвигает среднее по району так, что вывод получается обратный правде. Поэтому границы выбросов считаются и печатаются явно, а все сравнения идут по медианам.

## Как воспроизвести

```bash
uv run analiz run rent
```
