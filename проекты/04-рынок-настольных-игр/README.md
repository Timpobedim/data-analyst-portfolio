# Какие настольные игры покупают

**Вопрос:** какие жанры настольных игр растут и стоит ли ориентироваться на оценки?

**Данные:** 3 500 изданий за 2011–2025 годы: жанр, издатель, оценки критиков и игроков, цена и тираж. Набор воспроизводим по зерну и лежит рядом в `данные.csv`.

**Метод:** явный выбор актуального периода, доли жанров по годам, корреляция Спирмена между оценками и тиражом, критерий Манна–Уитни для сравнения оценок критиков и игроков.

## Главное

- Самый крупный жанр последних четырёх лет — семейные игры: **50,8%** тиража.
- Семейные и детские игры растут весь период, варгеймы сокращаются примерно вдвое.
- Оценки слабо связаны с тиражом (Спирмен **0,14**): ставка на «высокий рейтинг» сама по себе не окупается.
- Критики ставят оценки выше игроков, различие значимо, но эффект пренебрежимо мал.

## Что здесь показано отдельно

Данные за пятнадцать лет отвечают на вопрос «что покупали», а решение принимается про «что покупают». Поэтому актуальный срез (последние четыре года) выбран явно и обоснован в отчёте, а не взят молча.

Пропуски в оценках не заполняются средним: у мелких изданий рецензий просто нет, и подстановка среднего придумала бы рецензии, которых не было.

```bash
uv run analiz run boardgames
```
