# Продажи книжного магазина: разбор на SQL

**Вопрос:** какие книги дают выручку, как растут продажи и возвращаются ли покупатели?

**Данные:** три таблицы — 220 книг, 9 000 заказов и позиции этих заказов за полтора года. Наборы воспроизводимы по зерну и лежат рядом в `книги.csv`, `заказы.csv`, `позиции.csv`.

**Метод:** пять SQL-запросов на DuckDB — накопленные доли оконной функцией, ранги внутри групп, сравнение с предыдущим месяцем через `lag`, когорты по месяцу первой покупки.

## Главное

- Группа A (первые 80% выручки) — **119 книг из 220**, то есть 54,1% ассортимента.
- Самая доходная книга даёт **6,6%** всей выручки.
- Через месяц после первой покупки возвращается **58,2%** клиентов.
- Все расчёты сделаны одним SQL: оконных функций хватает и на накопленные доли, и на ранги, и на сравнение с прошлым месяцем.

## Что здесь показано отдельно

Этот проект существует ради самих запросов: на техническом собеседовании аналитика спрашивают не pandas, а `OVER (PARTITION BY ... ORDER BY ...)`, `lag`, `rank` и подзапросы. Поэтому все пять запросов приведены в отчёте целиком — их можно читать и обсуждать, а не только смотреть на результат.

```sql
SELECT название,
       выручка,
       выручка / sum(выручка) OVER () AS доля,
       sum(выручка) OVER (ORDER BY выручка DESC) / sum(выручка) OVER () AS накопленная_доля
FROM выручка
ORDER BY выручка DESC
LIMIT 10
```
