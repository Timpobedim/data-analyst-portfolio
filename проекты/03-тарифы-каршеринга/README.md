# Какой тариф каршеринга приносит больше

**Вопрос:** приносит ли пакетный тариф больше выручки на пользователя, чем поминутный?

**Данные:** 900 пользователей за шесть месяцев, поездки, минуты и выручка по двум тарифам в трёх городах. Набор воспроизводим по зерну и лежит рядом в `данные.csv`.

**Метод:** агрегирование до одного наблюдения на пользователя, проверка равенства дисперсий (критерий Левена), критерий Стьюдента или Уэлча по её результату, доверительные интервалы и размер эффекта.

## Главное

- Пакетный тариф приносит в среднем на **1 671 ₽** в месяц больше: 3 206 ₽ против 1 534 ₽ на пользователя.
- Различие значимо (p < 0,0001), а размер эффекта большой (d = 1,66) — это не «статистически заметная мелочь».
- Доверительные интервалы не пересекаются: 3 091–3 320 ₽ против 1 454–1 614 ₽.
- Во всех трёх городах направление одинаковое, поэтому вывод не объясняется особенностями одного рынка.

## Что здесь показано отдельно

Сравниваются не отдельные месяцы, а пользователи: иначе активный клиент попадёт в выборку шесть раз и создаст видимость большего объёма данных, чем есть на самом деле.

## Как воспроизвести

```bash
uv run analiz run carsharing
```

**Чего это не доказывает:** это наблюдение, а не эксперимент. Пакетный тариф выбирают те, кто и так ездит больше, поэтому перевод всех пользователей на него не даст такого прироста.
